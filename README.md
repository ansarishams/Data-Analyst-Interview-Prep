## Project-Based Practice

I am also practicing interview questions using real project datasets instead of only working with random questions.

For example, if a company wants to understand why customer churn is increasing, I would try to:

1. Understand the business problem
2. Explore the available data
3. Identify important columns
4. Create business questions
5. Write SQL queries
6. Analyze the results
7. Create visualizations when required
8. Find useful insights
9. Think about possible business actions

This approach helps me prepare for practical and scenario-based questions that can come up in Data Analyst interviews.

---

## My Learning Approach

My overall approach is:

Dataset → Business Question → Analysis → SQL / Excel / Power BI → Insight

I am focusing more on understanding the problem rather than simply memorizing answers.

For every problem, I try to understand:

- What is the business problem?
- What data is available?
- What needs to be analyzed?
- Which tool is suitable?
- What does the result tell us?
- How can the result help the business?
